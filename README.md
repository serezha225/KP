# Мониторинг температуры пара в реакторе
Постановка задачи
Датчик технологической установки непрерывно формирует последовательность показаний температуры пара в реакторе X (диапазон значений от 100 до 220 °C). В программной реализации 40 показаний последовательно считываются из файла. Каждое показание X преобразуется по индивидуальной кусочной функции в индикатор технологического процесса Q: при X < 140 применяется формула (X-140)(X-140) / 18 + 8, при 140 ≤ X ≤ 180 применяется формула 2√(X-160+20) + 42, при X > 180 применяется формула 3*(X-180) + 60.
Штатный режим работы: от 140 до 180 °C. Значения вне этого диапазона рассматриваются как отклонение технологического процесса
